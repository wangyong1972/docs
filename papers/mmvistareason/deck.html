Two reasoning groups define the pipeline

  • Analytical tasks include science, mathematics, visual logic, and charts.
  • Real-world tasks include perception, counting, spatial reasoning, and GUI grounding.
  • Separate specialization addresses negative transfer under mixed-domain RL.

Cleaning preserves distinct questions per image

  • SHA-256, pHash, and CLIP similarity detect redundant image/question pairs.
  • The same image can retain multiple distinct questions.
  • Qwen3.5-122B-A10B normalizes language, answerability, instructions, and answer forms.
一图多问不应按图片 ID 整体删除。语义清洗也可能改写任务，生产环境应保留原文和转换记录。第 3.1 节。

Teacher cascades control supervision cost

  • A 4B model generates four responses for initial difficulty filtering.
  • Unresolved examples escalate through 9B, 27B, and 122B teachers.
  • A verifier checks answer correctness and reasoning consistency before accepting trajectories.
级联路由把昂贵 teacher 的调用集中在前级未解样本上。它产生的是相对于当前模型族的难度。第 3.2 节。

Answer-Likelihood Best-of-N

  • Candidate traces first pass correctness and format checks.
  • The teacher scores normalized final-answer log likelihood conditioned on each trace.
  • Selection favors a valid trace that strongly supports the answer while controlling answer-length bias.
答案概率不是独立的人类推理质量证明。需要关注 verifier 偏差与 teacher 自洽偏好。第 3.2 节。

RL prompts follow each model’s frontier

  • The corresponding SFT model produces eight rollouts per answer-verifiable prompt.
  • Scale-specific pass-rate intervals keep inconsistently solvable prompts.
  • Analytical and real-world subsets train separate GSPO experts from the SFT initialization.

Multi-teacher on-policy distillation

  • The student generates trajectories and receives domain-routed expert supervision.
  • Teacher top-32 distributions supervise the student’s own rollout positions.
  • The paper finds preferred KL direction varies with model scale.
MOPD 融合 expert 的能力。不要把它描述为直接合并权重或简单拼接离线 teacher traces。第 3.3 与 4.4 节。
