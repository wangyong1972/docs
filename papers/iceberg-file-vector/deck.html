FILE PR   Iceberg VECTOR   Parquet draft

FILE represents a byte range

  • The proposed FILE type can reference bytes inline or in an external file.
  • It defines a distinct nested type and TypeID instead of inheriting struct semantics.
  • The submitted API change forms one part of a broader FILE support sequence.
读取图片或音视频片段需要字节范围的结构语义。API 类型存在并不代表所有 engine 的读写、GC 和权限已经实现。
FILE PR   Iceberg VECTOR   Parquet draft

Derived nested field IDs protect schema evolution

  • Six nested fields derive their IDs from the containing FILE field ID.
  • ID assignment reserves the derived block against future columns.
  • Visitors receive dedicated FILE handling with a default struct fallback where appropriate.
类型系统必须防止 schema evolution 与内部字段 ID 冲突。普通 struct visitor 的兼容回退也需要逐个检查语义。

Version gating constrains rollout

  • The FILE PR gates the proposed type to format version 4.
  • Older table versions cannot silently acquire the new semantics.
  • Reader, writer, schema evolution, and table upgrade support need independent verification.
版本门槛保护兼容性。不能因为格式规范拟新增一个类型就宣称现有 Spark/Trino 环境均可使用。

Parquet #592 changes repetition semantics

  • The draft adds a VECTOR logical type and VECTOR repetition type.
  • SchemaElement.vector_length fixes the number of element slots per vector occurrence.
  • The VECTOR repetition level adds no definition or repetition level of its own.

A compatibility-first evaluation matrix
